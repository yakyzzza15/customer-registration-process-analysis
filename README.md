# Анализ процесса регистрации клиентов

Анализ бизнес-процесса регистрации клиентов-физлиц в отделениях банка.
Датасет — **4.4 млн событий** корпоративного кликстрима за январь–июль 2024.

## Задачи

1. Динамика по месяцам — количество регистраций и среднее время процесса
2. Детализация по формам — среднее время на 12 экранных формах
3. Дополнительные метрики — конверсия, возвраты, глубина процесса
4. Оценка изменений за 7 месяцев
5. Рекомендации для команды разработки

## Рабочий стек

Python (pandas) · MySQL (DBeaver) · Excel · Power BI

## Результаты анализа

- **125 742** успешных регистрации, рост +46% за 7 месяцев
- **Среднее время процесса:** 413 сек, стабильно
- **Найден баг логирования:** на форме идентификации `Submit > Response` фиксируется только в **53%** случаев
- **3 формы улучшены**, **5 требуют разбора** (регресс по времени или возвратам)
- **Форма 3 «Резидент»** — системный регресс: время +16%, возвраты +43%
